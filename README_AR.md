# منصة Malik Group لعرض وإدارة الأثاث

[English](README.md) | [العربية](README_AR.md)

> منصة مبنية بـLaravel لعرض منتجات الأثاث وتصنيفها وإدارتها، مع صور متعددة، أسعار، بحث وفلاتر، وتواصل مباشر مع العميل.

## نظرة عامة

مشروع Malik Group هو منصة ويب متخصصة بالأثاث والديكور، وتتكوّن من واجهتين رئيسيتين:

- **واجهة عامة للمتجر/الكتالوج** تسمح للزائر باستعراض الفئات والمنتجات؛
- **لوحة إدارة محمية** لإدارة المنتجات والفئات والصور وحالة النشر ومحتوى تذييل الموقع.

تم بناء المشروع كتطبيق Laravel Server-Rendered باستخدام Blade، مع Vite وTailwind CSS لبناء واجهة المستخدم. يعتمد الكتالوج ولوحة الإدارة على نفس نموذج البيانات، ما يجعل عرض المنتجات وإدارتها ضمن نظام واحد متكامل.

## الوظائف الرئيسية

### الواجهة العامة

تتضمن الواجهة العامة حالياً:

- الصفحة الرئيسية للكتالوج؛
- تصنيفات الأثاث؛
- المنتجات المميزة أو المضافة حديثاً؛
- استعراض المنتجات حسب الفئة؛
- البحث باسم المنتج؛
- فلترة السعر الأدنى والأعلى؛
- تقسيم النتائج إلى صفحات؛
- صفحات مستقلة لتفاصيل المنتجات؛
- معرض صور متعدد لكل منتج؛
- عرض الصور بوضع ملء الشاشة؛
- عرض السعر والعملة؛
- زر تواصل مباشر عبر WhatsApp باستخدام رقم المنتج؛
- تصميم متجاوب مع الموبايل والشاشات المختلفة.

المنتجات التي تظهر في الواجهة العامة هي المنتجات ذات الحالة `active` فقط.

### لوحة الإدارة

تشمل لوحة الإدارة المحمية:

- لوحة التحكم؛
- إدارة المنتجات؛
- إدارة صور المنتجات؛
- إدارة الفئات؛
- إدارة حالة نشر المنتج؛
- تعديل الأسعار وأرقام التواصل؛
- إعدادات تذييل الموقع؛
- تسجيل دخول خاص بالإدارة.

جميع مسارات الإدارة محمية بواسطة Middleware باسم `admin`.

## نموذج المنتج

النموذج الحالي للمنتج بسيط ومباشر، ويحتوي على:

- الفئة؛
- الاسم؛
- الوصف؛
- رقم التواصل؛
- السعر؛
- حالة النشر؛
- عدة صور مرتبة.

يدعم النظام حالياً حالتي `active` و`pending`، بينما الكتالوج العام يعرض المنتجات النشطة فقط.

## البحث والفلاتر

يدعم كتالوج المنتجات الفلترة حسب:

- الفئة؛
- اسم المنتج؛
- الحد الأدنى للسعر؛
- الحد الأعلى للسعر.

تُطبّق هذه الفلاتر على مستوى استعلام قاعدة البيانات، وتُحفظ مع الانتقال بين صفحات النتائج.

## صور المنتجات

يمكن ربط عدة صور بكل منتج مع ترتيب واضح للعرض. تعرض صفحة المنتج صورة رئيسية وصوراً مصغرة ومعرضاً بملء الشاشة.

يعتمد المشروع على Public Storage Disk في Laravel لتخزين الوسائط المُدارة.

## بيانات الكتالوج التجريبية

يتضمن المشروع Seeder لبيانات أثاث تجريبية ضمن فئات مثل:

- Living Room
- Bedroom
- Dining
- Home Office
- Storage & Shelving

هذه البيانات هدفها دعم التطوير والعرض التجريبي، ولا يجب اعتبارها دليلاً على المخزون الحقيقي الموجود في بيئة الإنتاج.

## التطوير المحلي

أوامر الإعداد الأساسية:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run build
```

كما يمكن تشغيل خدمات التطوير المحلية المتزامنة من خلال:

```bash
composer dev
```

يجب إبقاء إعدادات قاعدة البيانات والبريد وعنوان التطبيق وأي أسرار أخرى خارج المستودع.

## الاختبارات

يمكن تشغيل اختبارات الـBackend عبر:

```bash
composer test
```

وجود إعدادات الاختبار داخل المشروع لا يعني تلقائياً أن جميع الاختبارات والبناء تم التحقق منها في كل بيئة. يجب تقييم نتائج التشغيل والاختبارات بشكل مستقل عن التوثيق.

## النشر إلى Production

يحتوي المستودع على GitHub Actions Workflow للنشر إلى بيئة الإنتاج عند حدوث Push إلى `main`.

تقوم عملية النشر بالاتصال بالسيرفر عبر SSH، ثم تحديث الكود، تثبيت Composer Dependencies، تثبيت وبناء Frontend Assets، تشغيل Laravel Optimizations والمigrations، التأكد من Storage Link، تعديل الصلاحيات، وإعادة تحميل PHP-FPM وNginx.

أسرار SSH والبنية التحتية لا يتم تخزينها داخل هذا README، ويجب أن تبقى ضمن GitHub Repository Secrets وبيئة السيرفر.

## النطاق الحالي للمشروع

الوصف الأدق للمشروع هو **منصة كتالوج أثاث مع لوحة إدارة**، وليس متجر تجارة إلكترونية كامل.

المستودع الحالي يثبت وجود استعراض المنتجات، الفئات، الصور، الأسعار، البحث، الفلاتر، إدارة المحتوى، والتواصل المباشر مع العميل. أما سلة المشتريات والدفع الإلكتروني وإدارة الطلبات الكاملة فلا تظهر ضمن النطاق الحالي الذي تم التحقق منه.
